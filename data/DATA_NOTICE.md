# Data Notice

The source data used by this project are based on indicators published
by the Autoridad de Supervisión del Sistema Financiero (ASFI), Bolivia.

The inclusion of the compiled analytical workbook in this repository is
intended to facilitate transparent and reproducible research.

The software license of this repository applies to the original software
and code distributed with the project and does not automatically grant
ownership of, or relicense rights over, third-party source data.

Users should preserve the original source attribution when reusing or
redistributing data derived from the underlying source.
